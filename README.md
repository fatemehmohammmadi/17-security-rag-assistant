# 17 — Security RAG Assistant (Mini)

A tiny **Retrieval-Augmented Generation** style assistant over a security knowledge base using TF-IDF retrieval + templated answers (no paid API required). Great GitHub demo for “LLM + Security”.

## Run

```bash
pip install -r requirements.txt
python build_kb.py
python ask.py
```
